# 倪师推理链：方案 v1

2026-10-07 写，抽取之前登记。之后有改动另写补记并登记，不改本文件。

## 一、要做什么

第三版引擎的做法是「盘面条件 → 结论」，每条规则各自命中，再按属性取舍。结论和结论之间没有推导关系。

倪海厦看盘不是这样。他说「介绍命宫的时候，我们可以看到这个人的长相，这个人的个性。从个性上面可以知道这个人的行为模式。其实开始从命宫一看就已经知道成败」（T409）。他讲星的时候也是一步接一步，例如：

- 「天相……天上的宰相。所以天相星是一个佐才星。你如果是天相入命的人你适合去当人家的助理……」（T213）
- 「天相是什么，天上的宰相，是非常好的良佐，辅佐的人才，所以天相呢，一定是位高无权」（T214）

这次要做的：把这种「后一个判断从前一个判断推出来」的步骤，从倪海厦原话里逐条抽出来；引擎照这些步骤从盘面一层一层往后推，每个判断都写明是从哪个判断、按哪句原话推出来的。

## 二、判断分层

| 层 | 管什么 | 例 |
|---|---|---|
| 盘面 | 星、亮度、四化、宫位关系 | 命宫有天相；三方四正无左辅右弼 |
| 定性 | 这颗星或这个格局让这个人属于哪一类 | 帝星、主官、佐才、文官、教星、孤星 |
| 长相 | 外貌体型 | 脸方、个子不高 |
| 个性 | 性情 | 刚强、固执、性本孤、厚道 |
| 行为 | 做事的方式、容易做出的事 | 谁的话都不接受、不喜欢跟人来往 |
| 路线 | 走哪条路、适合做什么 | 当助理秘书、当公务人员教员、僧道 |
| 成败 | 成就高低、得失、贵贱 | 位高无权、事倍功半、前途黯淡 |

主链按倪海厦的顺序：盘面 → 定性 → 长相、个性 → 行为 → 路线 → 成败。

另有「财、婚姻、子女、父母、兄弟、朋友合伙、健康、祖业田宅、福德、官非、意外、寿元、其他」这些领域（与知识库相同）。原话里有推导的照样抽，标明领域，但不算在主链的层次里。

## 三、两种步

- **定性步**（起步）：盘面条件 → 一个判断。条件写法与知识库完全相同（见抽取说明）。
- **推理步**（承接）：一个或几个判断（可以再加盘面条件）→ 后一个判断。

推理步必须是倪海厦自己说出来的推导：

- 原话里有「所以、因为、代表、就是说、那就、就会、难怪、因此、遇到这种人……」这类承接；
- 或者紧接着的下一句是在讲前一个判断的后果。例如先说「是佐才星」，紧接着说「适合当助理」。

只是并列几个特征，或同一句里列举几样，不算推理步。倒装的（先说结论、后说原因）按因果方向记。

每一步都要写：

- 原话摘录：逐字连续的一段；
- 出自哪条（T 编号）；
- 宫、适用（先天、大限、流年、小限）；
- 是不是讲某个具体命例时说的（命例特指）。

## 四、抽取

1. 材料：知识库当初分好的 35 批（kb_packets_v2：1374 条倪师原话，每批附前后文），batch.json 与 context.txt 逐字节复制，核对 SHA-256。
2. 每批由两名抽取者各自独立抽取。抽取者是 Opus 5.5、推理档位 high 的只读子代理，只读本批文件夹，最终回复一份 JSON。
3. 第三名裁定者看原话与两份抽取，逐步定稿：
   - 两人都抽到的，核对后收；
   - 只有一人抽到的，决定收或不收，写理由；
   - 层、宫、条件写错的，改正并写明。
4. 先试抽 2 批（K06 七杀天相天梁等，K10 命宫与三方四正），每批两名抽取者。试抽只用来看说明写得清不清楚。改定的说明登记后，35 批全部重抽，K06、K10 也重抽。试抽结果另存，不进知识库。
5. 报告两名抽取者的一致程度：
   - 按条：两人对「这条原话有没有推理步」判断一致的比例；
   - 按步：只有一人抽到的步占多少。

## 五、判断归一

不同讲次说同一个判断，用词不一样，例如「佐才星」「良佐」「辅佐的人才」。不归一，链就接不上。

1. 抽取时，每个判断写两样：「判断」是一个简短的名字，尽量用倪海厦最常用的说法；「原话说法」是原话里的词。
2. 全部步定稿后，把所有不同的「判断」按层分组列出，每个附一两例原话。两名归类者独立归类：
   - 同义的归成一个结点；
   - 一个说法里是并列的两个判断（如「刚强固执」），拆成两个结点；本身是一个整体意思的（如「刚愎自用」）不拆；
   - 拿不准的不合并；
   - 层分错的可以改层，写明理由。
3. 第三名裁定者定稿，报告两名归类者的一致程度。归一表定稿后登记，之后不改。
4. 推理步的前提在归一后可能是几个结点，要全部推出来，这一步才算成立。

## 六、引擎第四版

1. 读盘与条件求值完全沿用第一版：ni_engine_v1 的 eval_rule、空宫借对宫、任一宫的用法、五个算子。第一至三版的文件一个不改。
2. 只做先天（本命盘）。大限、流年里的推理步照样抽、照样存，只报条数，引擎这一版不用。
3. 按宫推理：
   - 每一宫先用定性步：条件成立，就在这一宫得出那个判断；
   - 再反复用推理步：前提结点在这一宫都已得出，附加的盘面条件也成立，就得出后一个判断；
   - 推理步的「宫」写某宫的，只在那一宫用；写「任一宫」的，按第一版任一宫的用法在各宫用；
   - 一直推到没有新判断为止，最多 8 轮。
4. 每个判断都带完整推导：从哪些盘面条件起，经过哪几步，每步的 T 编号与原话。同一个判断有几条推法时都留，成稿显示最短的那条。
5. 同一宫、同一层里方向相反（一吉一凶）的判断都列出，标「两说」。不投票，不按条数取舍。
6. 成稿：最前面加「推理链」一节，先写命宫这条主链，再写身宫和财帛、官禄、迁移，最后写其余各宫。后面接第三版成稿，原样不动，作对照。

## 七、检验

登记后照做，结果不论好坏都报。

### 1. 步是不是倪海厦说的（忠实度）

- **脚本核对**：每步原话摘录必须是该条原话的逐字片段，去掉空白后比较。不合格的步不进引擎，条数照报。
- **独立核查**：全部步再交给一名没参与抽取和裁定的核查者（Opus 5.5 high）逐步判。推理步判原话是不是明说了「由前提推出结论」；定性步判是不是由这些盘面条件得出这个判断。
- 判「不成立」的步不进引擎。报告成立的比例，并列出不成立的例子。

### 2. 在随机盘上推得动推不动（覆盖，只作描述）

用新的 600 张留出随机盘（种子 METIS-V4-留出随机盘-20261007，生成办法同第三版留出盘）。报告：

- 命宫主链至少用到一步推理步、走到「行为、路线、成败」任一层的盘占多少；走到「成败」层的占多少；
- 每张盘命宫链的推理步数（中位数、四分位）、最长一条链有几步；
- 命宫的判断里，至少经过一步推理步才得出的占多少；
- 每张盘「两说」有几处。

### 3. 能不能复现倪海厦自己读过的命例（主检验）

1. **人**：与 M4 相同的 28 位命例，用同一批候选命盘。
2. **倪师判断集**：这个人讲述时段内、标了「命例特指」、适用先天、宫为命宫或身宫的步，它们得出的判断（归一后的结点）。没有这类判断的人不计入，人数照报。
3. **引擎**：剔除这个人讲述时段内的全部步（不论是否命例特指），用其余的步推。
4. **得分**：倪师判断集里，引擎在这张盘的命宫（含身宫）推出来的比例。有几张候选盘时，取各候选都推出来的。
5. **对照**：同一套剔除后的步，在 600 张留出盘上算同样的得分。这个人自己那张盘的得分在 600 张里排第几，记作 u：
   - u = （得分高于本人盘的张数 ＋ 0.5 × 得分相同的张数）÷ 600；
   - 0 表示比所有随机盘都好，0.5 表示和随机盘一样。
6. **统计**：
   - 主统计量是计入各人 u 的平均数；
   - p 值：每人改从 600 张留出盘里随机抽一张、当作「本人盘」算 u，重复 10000 次（种子 METIS-V4-复现检验-20261007），平均 u 不大于实测值的比例；
   - 单侧，p < 0.05 算通过。
7. **另报（只作描述）**：
   - 只用定性步、不用推理步时同样的得分与 u，看推理步多复现了多少；
   - 倪师判断集里推理步的那几条连线（前提 → 结论），引擎在本人盘上是不是也是这样推出来的，报复现比例。

### 4. 可追溯

成稿里每个判断都要能追到 T 编号与原话，脚本核对，要求 100%。

## 九、事先写明的局限

- 「格」这种条件引擎不求值，与第三版相同，带「格」的步用不上。
- 归一由 AI 做。合得太粗，会接出倪海厦没说过的链；分得太细，链会断。用两名归类者加裁定、并报告一致程度来约束。
- 讲述时段很宽：28 人的时段覆盖 1374 条里的 816 条。剔除时连同时段里讲通则的话一起剔除，所以主检验偏保守。
- 设计者（我）设计主检验之前读过部分命例原话，不是盲的。主检验是事先登记的检验，但设计者不盲，照实写。
- 只用《天纪》倪海厦原话，不用《全书》补层：这次要做的是倪海厦的推法；《全书》以条文为主，要不要另做，等这一版做完再定。
